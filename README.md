# Puti-AI 雲端成績平台 (Puti-AI Grade)

> 全國教師專用自訂發布 × 家長極速手機查詢系統  
> 🍎 國小鼓勵模式／🎓 國高中五標模式自由切換 • 零伺服器儲存 • 老師電腦關機 24h 照常查詢

🌐 **線上使用網址**：[https://puti001.github.io/puti-ai-grade/](https://puti001.github.io/puti-ai-grade/)

## 🌟 核心特色

1. **國小／國高中學段自由切換**：
   - 🍎 **國小鼓勵模式**：關閉五標與排名比較，凸顯「各科均衡能力雷達圖」、「進步星號 ⭐」與「導師溫暖小語」。
   - 🎓 **國高中五標模式**：開啟「頂標、前標、均標、後標、底標」彩色落點指標條，讓會考模考學生一眼掌握級距落點。
2. **家長手機極速查榜（免記密碼）**：
   - 告別學生改密碼隔天就忘記的行政惡夢！
   - 家長在 LINE 點開連結，只需輸入「座號 ＋ 出生月日 4 碼（例如 0101）」，0.1 秒秒開。
3. **零伺服器儲存 • 老師電腦關機依然可查（解法 1 架構）**：
   - 成績資料 100% 存放在各校老師自己的 Google 雲端硬碟試算表。
   - 平台不設中央資料庫、不持有、不轉存任何學生名冊與分數，徹底杜絕個資外洩法律風險。
4. **完整免責與隱私聲明**：
   - 清楚載明本服務為教育公益性質，平台不維護各班私有備份，正式學籍以教務處用印成績單為準。

---

## 🚀 老師使用步驟

1. 點開 [Puti-AI 雲端成績平台](https://puti001.github.io/puti-ai-grade/)。
2. 點擊 **`🔗 綁定我的 Google 試算表`**，貼上您的班級成績試算表共用連結。
3. 自由勾選您要呈現給家長的項目（五標長條圖、雷達圖、趨勢線、AI 建議）。
4. 點擊 **`📋 複製 LINE 通知文案`**，發布到班級群組即大功告成！
